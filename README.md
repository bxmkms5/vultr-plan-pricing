## Vultr 的方案分几类，各适合什么

Vultr 的方案按资源隔离方式和用途分五大类，Windows 另外作为系统选项单独算授权费。

- **Cloud Compute（共享 vCPU）**：最便宜的一档，分 Regular Performance（上一代 Intel CPU + 普通 SSD）、High Performance（新款 AMD EPYC 或 Intel Xeon + NVMe）、High Frequency（3GHz+ Xeon + NVMe）三个档位。适合博客、低流量网站、开发测试、小型数据库。
- **VX1（独享 vCPU）**：目前主推的产品线，官方称每美元性能最高比超大规模云厂商的效率优化方案好 82%，15 秒内即可开通，网络最高 50 Gbps，支持从高性能块存储启动，分通用型和内存优化型。
- **Optimized Cloud Compute（独享 AMD EPYC vCPU）**：分通用、CPU 优化、内存优化、存储优化四个方向，对应关系数据库、视频编码、缓存、MongoDB 这类不同负载。
- **Cloud GPU**：AMD 和 NVIDIA 的多款数据中心 GPU（包括 MI325X、H100、L40S 等），按需按小时计费。
- **Bare Metal**：整机独占的物理服务器。

所有实例基于 KVM 虚拟化，DDoS 防护包含在网络里，不需要额外购买。

## 新用户赠金怎么领：高额 30 天和等额 365 天的区别

新用户赠金主要有两种玩法：高额但短期的，和等额但长期的。长期使用选后者更划算。

目前能整理到的活动有这几类：

- **300 美元赠金**：通过活动注册并充值激活后到账，有效期 30 天。
- **等额赠送**：充 10 送 10，最高充 100 送 100，赠金有效期 365 天，支持信用卡和 PayPal 付款。这个等额赠送在部分渠道以 VULTRMATCH 的名义出现过，注册时以活动页实际显示为准。
- **250 美元赠金**：30 天有效，需用信用卡激活。
- **200 美元赠金**：激活后获得 30 天试用权限。
- **3 美元小额赠金**：关注 Vultr 官方推特并按活动要求发推可得，新老用户均可参与（以活动页为准）。

30 天有效期意味着什么？拿 6 美元的 Basic 算，一个月跑满也就花 6 美元，300 美元赠金根本用不完，剩下 294 美元到期作废。等额赠送则不同：充 100 送 100、365 天有效，相当于这一年账单打了对折。打算在 Vultr 长期待下去，等额赠送的实际收益远高于那几个 30 天的大额赠金；只是想开几台机器跑几天测试，300 美元那种反而合适。

支付方式上有个坑要留意：Vultr 本身支持支付宝，但部分新客活动限制了支付渠道，激活赠金时可能要求信用卡或 PayPal。注册时如果优惠没有自动生效，可以在充值页的 Enter Code 输入框手动激活。[👉 领取 Vultr 新用户赠金并注册账户](https://bit.ly/VulTR)

## 按小时计费的规则，以及几个容易踩的坑

按小时计费是 Vultr 的默认规则，最大的坑是：**关机不等于停止计费**。实例只要存在就按小时扣费，只有彻底销毁才停，用完的机器记得删，别只是关机留在账户里。

流量超出套餐额度后按 0.01 美元/GB 收费。这个单价在主流云厂商里属于偏低的一档——作为参照，AWS 的出口流量价格大致从 0.08 到 0.12 美元/GB 起步，差出一个数量级。

好消息是试用成本很低。Basic 折算下来开一整天两毛美元上下，完全可以开一台机器跑几小时测试，不满意就删掉，几乎不花钱。[👉 开通 Cloud Compute 按小时计费方案](https://www.vultr.com/pricing/?ref=7268283)

## 和 DigitalOcean、Hetzner、AWS 比处于什么位置

横向比价的话，Vultr 的位置很清楚：比大厂好算账，比欧洲平价厂商覆盖广。

同等配置下，Vultr 和 DigitalOcean 的价格接近，但机房选择更多。如果把使用范围限定在欧洲，Hetzner 通常更便宜，这一点没什么争议。至于 AWS、GCP 这类超大规模厂商，双方不在一个计费逻辑里：除了上面提到的出口流量差价，Kubernetes 控制平面在 AWS 每月要收 70 多美元，Vultr 免费；管理数据库、对象存储这些配套两方都有，但 Vultr 的账单页起码不用请人解读。

## 常见问题

**Vultr 支持支付宝吗？**
支持。官方支持支付宝付款，但部分新客活动对支付方式有限制，激活特定赠金可能要求信用卡或 PayPal，以活动条款为准。

**关机之后还扣费吗？**
会。按小时计费，关机不停止计费，只有删除实例才停。

**自己充的钱会过期吗？**
不会。充值余额没有有效期，只有赠送的赠金有期限，大多 30 天，等额赠送的是 365 天。

**可以注册多个账号叠加赠金吗？**
不建议。多账号信息关联会被识别，有全部账号被封禁的先例。

**Windows 授权能用自己的吗？**
不能。开通 Windows 实例时授权自动包含并单独计费，已有授权无法转移到 Vultr。

**超出月流量怎么算？**
按 0.01 美元/GB 计费，只对超出部分收费。
